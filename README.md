Calculadora Simples em JavaScript

Objetivo
Criar uma página web simples utilizando **JavaScript** que permita realizar operações matemáticas básicas, aplicando os conceitos aprendidos na última aula, como:

- Variáveis
- Operadores aritméticos
- Interação com o usuário via **prompt** e **alert**
- Exibição de resultados com **document.write** e **console.log**
- Botões para acionar funções



Requisitos
1. Criar um botão na página que exiba um **alert** de boas-vindas ao site.  
2. Solicitar ao usuário dois números utilizando **prompt**.  
3. Realizar as quatro operações aritméticas básicas:
   - Soma
   - Subtração
   - Multiplicação
   - Divisão
4. Exibir os resultados utilizando **document.write**.  
5. Registrar os resultados também no **console** usando **console.log**.



Tecnologias Utilizadas
- HTML5
- CSS3 (opcional para estilo)
- JavaScript puro (Vanilla JS)
